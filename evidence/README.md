# Evidence Directory

Packet execution evidence is stored at:

`evidence/<packet-id>/<UTC-timestamp>/`

Read `docs/evidence/EVIDENCE_RETURN_PROTOCOL.md` and `docs/evidence/MINIMAL_OPERATOR_HANDOFF.md` before writing evidence.

The operator should receive only the short `OPERATOR_RETURN.md`; complete logs, tests, reviews and gates remain in the packet directory and pull request.
